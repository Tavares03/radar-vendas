# Playbooks

Um playbook descreve, em YAML e sem programação, o que é risco e o que é bom atendimento num
setor: frases proibidas (com exceções), informações obrigatórias, objeções comuns com boas
respostas, sinais de compra e os critérios da nota.

O guia completo está em [docs/PLAYBOOKS.md](../docs/PLAYBOOKS.md).
